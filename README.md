# Farishta brand

Design assets for Farishta and its apps.

| Folder | Contents |
|---|---|
| `mascot/` | The Farishta companion: glow, emerald and 3D renders, the 3D design brief, the six-expression companion pack (`farishta-companion/`), soft companion and smooth rig animation packs |
| `mascot/source/` | Working files behind the mascot: sprite frames, rig and animation prototypes, QA checks |
| `logos/farishta/` | Farishta logo, tab icon, share preview, and the farishta.si website icons |
| `logos/family-dhikr/` | Family Dhikr dome logo, tab and app icons, share image (used by dhikr.farishta.si) |
| `widget/` | iPhone home-screen widget concept and widget prototype |
| `majlis/` | Majlis companion design references and app screenshots |

Mascot states: happy, greeting, thinking, celebrating, sleepy, sad. Use "sad" for connection problems only, never to shame anyone about worship.
